# Trans-Hub Localizer · 플러그인 현지화

**Obsidian 커뮤니티 플러그인을 내 언어로 표시하세요.**

Trans-Hub Localizer는 Obsidian 커뮤니티 플러그인에 번역 및 UI 현지화를 제공하는 플러그인입니다. 감지된 플러그인 내장 번역을 우선 보존하고, 공유 번역으로 누락된 내용을 보완하며, 게시된 업데이트를 자동으로 동기화합니다. 기본적으로 런타임에 번역을 적용하며, 플러그인 파일을 수정하거나 노트를 번역 또는 업로드하지 않습니다.

[Obsidian에서 설치](obsidian://show-plugin?id=trans-hub-plugin-localizer) · [현지화 진행 상황 보기](https://trans-hub.net/ecosystems/obsidian) · [피드백 및 커뮤니티](https://github.com/SakenW/Trans-Hub/discussions)

## 시작하기

**Obsidian 1.11.4 이상**, Trans-Hub 계정, 그리고 인증 및 동기화를 위한 네트워크 연결이 필요합니다. 데스크톱과 모바일을 지원하지만, 고급 파일 호환성 패치는 데스크톱에서만 사용할 수 있습니다.

1. **설정 → 커뮤니티 플러그인**에서 **Trans-Hub Localizer**를 설치하고 활성화합니다.
2. 플러그인 설정을 열고 Trans-Hub 계정에 연결합니다. AI 모델, 모델 공급자 계정 또는 API Key를 설정할 필요가 없습니다.
3. 번역 언어를 확인합니다. 플러그인이 활성화된 커뮤니티 플러그인을 자동으로 찾아내며, 현지화하지 않을 플러그인은 제외할 수 있습니다.

이미 게시된 번역은 바로 재사용합니다. 누락된 내용은 현지화 요청으로 자동 제출되며, 백그라운드에서 처리되고 게시된 후 동기화됩니다. 처리, 게시 또는 호환성 검사를 기다리는 내용은 일시적으로 원문으로 남을 수 있습니다.

수동 설치 시 같은 [GitHub Release](https://github.com/SakenW/trans-hub-obsidian-localizer/releases)에서 `main.js`, `manifest.json`, `styles.css`를 내려받아 `<vault-config-dir>/plugins/trans-hub-plugin-localizer/`에 넣으세요. 서로 다른 버전의 파일을 섞어 쓰지 마세요.

## 핵심 기능

| 기능 | 실제 동작 |
| --- | --- |
| 내장 번역 우선 | 감지된 현재 플러그인의 내장 번역을 보존하고 누락된 문구를 보완합니다. 명시적으로 검토된 수정 번역만 해당 내장 문구를 대체할 수 있습니다. |
| 공유 번역 | 서로 다른 사용자가 게시된 결과를 재사용하며, 누락된 내용은 공유 현지화 과정으로 들어갑니다. |
| 자동 동기화 | 시작할 때 검증된 캐시 번역을 먼저 복원하고, 실행 중에도 계속 업데이트를 확인합니다. 새 번역을 받으려면 네트워크 연결이 필요합니다. |
| 업데이트 후 호환 재사용 | 항목별 호환성 검사를 통과한 런타임 번역은 플러그인 버전을 넘어서 사용할 수 있습니다. 모호하거나 호환되지 않는 내용은 건너뜁니다. |
| UI 적용 범위 | 안전하게 식별할 수 있는 이름, 설명, 설정, 버튼, 명령, 알림, 옵션, 도구 설명, 입력 안내, 접근성 레이블 및 일부 동적 문구를 지원합니다. |
| 플러그인 README 텍스트 | 일치하는 게시된 README 번역이 있으면 커뮤니티 플러그인 상세 페이지의 지원되는 텍스트를 현지화할 수 있습니다. README와 핵심 UI 적용 범위는 별도로 계산합니다. |

런타임에서는 적용 조건에 따라 출처 식별, 범위, 의미 역할, 형식 및 동적 자리표시자를 확인합니다. 모든 플러그인의 전체 UI가 완전히 번역됨을 보장하지는 않습니다.

## 모든 언어 지원

대상 언어는 고정 목록에 제한되지 않습니다. 자주 쓰는 언어를 선택하거나 다른 언어 입력란을 통해 언어 식별자를 입력하여 지역 및 문자 변형을 보존할 수 있습니다.

빠른 선택에는 **중국어 간체, 중국어 번체, 영어, 일본어, 한국어, 독일어, 프랑스어, 스페인어, 브라질 포르투갈어, 러시아어**가 포함됩니다. 그 밖에도 이탈리아어(`it`), 아랍어(`ar`), 우크라이나어(`uk`), 세르비아어 라틴 문자 변형(`sr-Latn`) 등을 사용할 수 있습니다. 개별 번역의 이용 가능성과 품질은 게시된 결과 및 해당 언어에서 이용 가능한 처리 서비스에 따라 달라집니다.

여기서 말하는 것은 **다른 플러그인의 번역 언어**입니다. Trans-Hub 자체 설정 UI는 현재 중국어 간체와 영어를 제공하며, 다른 언어에서는 영어로 대체됩니다. 페이지 상단의 언어 링크는 이 README의 읽기 언어만 전환합니다.

## 번역 품질 및 지원 범위

현재 Trans-Hub 번역의 대부분은 기계 생성이며 사람이 교정하지 않았습니다. 플러그인은 번역의 출처와 검토 상태를 구분합니다. 출처 및 호환성 검증을 통과했다고 해서 번역 정확성이 사람의 검토를 거쳤다는 뜻은 아닙니다.

이 과정은 Obsidian 공식 커뮤니티 디렉터리와 신뢰할 수 있는 업스트림 출처를 통해 신원과 버전을 검증할 수 있는 커뮤니티 플러그인을 대상으로 합니다. BRAT를 통한 설치, 비공개 플러그인 또는 임의의 로컬 수정에는 호환성이 자동으로 보장되지 않습니다. 현재 출처 언어 과정은 영어를 사용합니다.

노트의 Markdown 편집기, 읽기 보기, 코드, 스크립트 및 편집 가능한 내용은 모두 제외됩니다. README 현지화는 커뮤니티 플러그인 상세 페이지로만 한정되며 노트 번역을 활성화하지 않습니다.

## 개인정보 보호 및 선택적 파일 패치

- 로컬 스캔은 플러그인 버전과 지원되는 UI 문구를 식별하는 데 사용되며, 스캔한 UI 텍스트나 노트는 업로드하지 않습니다.
- 요청에는 플러그인 신원, 버전, 대상 언어, 적용 개수 및 암호학적 다이제스트가 포함됩니다. 계정 인증과 번역 다운로드에는 네트워크 접근이 필요합니다.
- 자격 증명에는 Obsidian 보안 저장소를 사용합니다. 서버 측 처리 방식은 [개인정보 처리방침](https://trans-hub.net/zh-CN/legal/privacy)을 참조하세요.
- 기본 런타임 현지화는 플러그인 파일을 다시 쓰지 않습니다. 비활성화하면 번역 값이 남아 있는 런타임 텍스트를 복원하고, 다른 플러그인이 그 뒤에 능동적으로 변경한 내용은 보존합니다.

**고급 호환성 모드는 데스크톱 전용이며 기본적으로 꺼져 있습니다.** 조건을 충족하는 각 플러그인에 대해 사용자가 직접 패치를 적용해야 합니다. 패치는 정확한 버전 및 산출물에 연결되고 검증된 정적 UI 문구만 수정하며, 먼저 백업과 적용 기록을 저장합니다. 파일이 패치 후 다이제스트와 계속 일치할 때만 복원합니다. 플러그인 업그레이드나 외부 수정은 보존되고 충돌로 보고됩니다. 패치를 적용하거나 복원한 후에는 대상 플러그인을 다시 불러와야 합니다. 패치는 절대로 노트를 수정하지 않습니다.

## 자주 묻는 질문

**API Key가 필요한가요?** 아닙니다. Trans-Hub 계정에 연결하면 되며 모델이나 API Key를 설정할 필요가 없습니다.

**휴대폰에서도 사용할 수 있나요?** 예. 런타임 현지화는 모바일과 데스크톱을 지원합니다. 파일 호환성 패치는 데스크톱에서만 제공합니다.

**일부 텍스트가 아직 번역되지 않은 이유는 무엇인가요?** 번역을 기다리고 있거나, 출처를 검증할 수 없거나, UI를 안전하게 식별할 수 없기 때문일 수 있습니다. 플러그인 상태를 확인하세요. 아직 게시된 번역이 없다고 해서 그 언어를 지원하지 않는다는 뜻은 아닙니다.

**플러그인에 이미 중국어가 있으면 어떻게 하나요?** 감지된 내장 번역을 우선 보존하고, 공유 번역으로 누락된 부분을 보완합니다. 검토된 수정은 별도의 명시적 예외입니다.

**플러그인 업데이트 후에는 어떻게 하나요?** 호환성을 다시 확인합니다. 재사용할 수 있는 런타임 항목은 계속 적용되고, 호환되지 않는 항목은 새 버전의 번역을 기다립니다. 파일 패치는 여전히 정확한 일치를 요구합니다.

**오프라인으로 사용할 수 있나요?** 예. 이전에 캐시되고 검증된 번역을 재사용할 수 있습니다. 계정 인증, 누락된 내용 처리 및 새 번역 다운로드에는 네트워크 연결이 필요합니다.

## 빌드 및 라이선스

Node.js 24 및 pnpm 10.34.4를 사용합니다.

```bash
pnpm install --frozen-lockfile
pnpm lint
pnpm type-check
pnpm test
pnpm verify:public-copy
pnpm build
```

Release 태그는 `manifest.json`, `package.json`, `versions.json`과 일치해야 합니다. `1.0.0` 미만 버전은 공개 베타입니다. [Apache-2.0](../LICENSE) 라이선스를 사용합니다.
