# Trans-Hub Localizer · プラグインのローカライズ

**Obsidian コミュニティプラグインをあなたの言語で表示します。**

Trans-Hub Localizer は、Obsidian コミュニティプラグインに翻訳と UI ローカライズを提供するプラグインです。検出したプラグイン内蔵訳を優先し、共有訳で不足を補い、公開済み更新を自動同期します。既定では実行時に訳文を適用し、プラグインファイルを変更せず、ノートを翻訳またはアップロードしません。

[Obsidian にインストール](obsidian://show-plugin?id=trans-hub-plugin-localizer) · [ローカライズの進捗](https://trans-hub.net/ecosystems/obsidian) · [フィードバックとコミュニティ](https://github.com/SakenW/Trans-Hub/discussions)

<!-- section: getting-started -->
## はじめに

**Obsidian 1.11.4 以降**、Trans-Hub アカウント、認可と同期用のネットワーク接続が必要です。デスクトップとモバイルをサポートしますが、高度なファイル互換パッチはデスクトップ専用です。

1. **設定 → コミュニティプラグイン** で **Trans-Hub Localizer** をインストールして有効にします。
2. プラグイン設定を開き、Trans-Hub アカウントに接続します。AI モデル、モデル提供元アカウント、API Key の設定は不要です。
3. 翻訳言語を確認します。有効なコミュニティプラグインは自動検出され、不要なものは除外できます。

公開済み訳文は直接再利用されます。不足内容はローカライズ要求として自動送信され、バックグラウンド処理と公開後に同期されます。処理、公開、互換性確認待ちの内容は一時的に原文のままの場合があります。

手動インストールでは、同じ [GitHub Release](https://github.com/SakenW/trans-hub-obsidian-localizer/releases) から `main.js`、`manifest.json`、`styles.css` を取得し、`<vault-config-dir>/plugins/trans-hub-plugin-localizer/` に置きます。異なるバージョンのファイルを混在させないでください。

<!-- section: use-cases -->
## こんな用途に

- コミュニティプラグインの設定、コマンド、画面を自分の言語に翻訳したい。
- AI モデルや API キーを自分で設定せず、共有された訳文を利用したい。
- デスクトップとスマートフォンで利用し、プラグイン更新後も訳文の互換性を自動確認したい。

<!-- section: capabilities -->
## 主な機能

| 機能 | 実際の動作 |
| --- | --- |
| 内蔵訳を優先 | 現在のプラグインで検出した内蔵訳を保持し、不足文言を補います。明示的にレビューされた修正訳だけが対応する内蔵文言を置換できます。 |
| 共有翻訳 | ユーザー間で公開済み成果を再利用し、不足内容は共有ローカライズ工程に入ります。 |
| 自動同期 | 起動時に検証済みキャッシュ訳を復元し、実行中も更新を確認します。新しい訳の取得にはネットワークが必要です。 |
| 更新後の互換再利用 | 項目ごとの互換性確認に通った実行時訳はプラグインの版をまたいで使用できます。不明確または非互換の内容はスキップされます。 |
| UI の対象範囲 | 安全に識別できる名称、説明、設定、ボタン、コマンド、通知、選択肢、ツールチップ、入力ヒント、アクセシビリティラベル、および一部の動的文言を対象にします。 |
| プラグイン README の文言 | 対応する公開済み README 訳がある場合、コミュニティプラグイン詳細ページの対応文言をローカライズできます。README と中核 UI の対象範囲は別に数えます。 |

実行時には適用条件により、ソース識別、範囲、意味上の役割、形式、動的プレースホルダーを確認します。すべてのプラグインの全 UI を完全に翻訳することは約束しません。

<!-- section: languages -->
## 全言語に対応、プリセット以外も選択可能

よく使う言語を選択するほか、言語タグを入力して地域や文字体系の違いを保持できます。訳文を利用できるかどうかは、対象内容の処理と公開の状況によって決まります。

クイック選択は **簡体字中国語、繁体字中国語、英語、日本語、韓国語、ドイツ語、フランス語、スペイン語、ブラジルポルトガル語、ロシア語** です。イタリア語（`it`）、アラビア語（`ar`）、ウクライナ語（`uk`）、セルビア語ラテン文字変種（`sr-Latn`）なども選べます。個別の訳の可用性と品質は、公開済み成果とその言語で利用可能な処理サービスに依存します。

ここでいう言語は **他のプラグインの翻訳言語** です。Trans-Hub 自身の設定 UI は現在、簡体字中国語と英語を提供し、その他の言語では英語にフォールバックします。上部の言語リンクはこの README の表示言語だけを切り替えます。

<!-- section: quality -->
## 翻訳品質とサポート範囲

このプラグインはコミュニティプラグインの画面を対象としています。ノートやウェブページの翻訳、端末上での LLM によるリアルタイム翻訳は行いません。

現在の Trans-Hub 訳の多くは機械生成であり、人手校正されていません。プラグインは訳文のソースとレビュー状態を区別します。ソースおよび互換性の検証に通っても、訳の正確さが人手でレビューされたことを意味しません。

この工程は、Obsidian 公式コミュニティディレクトリと信頼できる上流ソースを通じて識別と版を検証できるコミュニティプラグイン向けです。BRAT 経由の導入、非公開プラグイン、任意のローカル変更には自動的な互換保証はありません。現在のソース言語工程は英語を使います。

ノートの Markdown エディター、閲覧ビュー、コード、スクリプト、編集可能な内容は除外されます。README のローカライズはコミュニティプラグイン詳細ページだけに限られ、ノート翻訳は有効にしません。

<!-- section: privacy -->
## プライバシーと任意のファイルパッチ

- ローカルスキャンはプラグインの版と対応 UI 文言の識別に使われ、スキャンした UI 文言やノートはアップロードしません。
- 要求にはプラグイン識別、版、対象言語、対象数、暗号学的ダイジェストを含みます。アカウント認可と訳文ダウンロードにはネットワークが必要です。
- 認証情報は Obsidian の安全なストレージを使います。サーバー側の処理は[プライバシーポリシー](https://trans-hub.net/zh-CN/legal/privacy)を参照してください。
- 既定の実行時ローカライズはプラグインファイルを書き換えません。無効化時は訳文値のままの実行時テキストを復元し、他プラグインによる後の変更は保持します。

**高度な互換モードはデスクトップ専用で、既定では無効です。** 条件を満たす各プラグインに対し、利用者が能動的にパッチを適用する必要があります。パッチは正確な版と成果物に結び付いた検証済みの静的 UI 文言だけを変更し、先にバックアップと受領記録を保存します。ファイルがパッチ後のダイジェストに一致する場合だけ復元します。プラグイン更新や外部変更は保持され、競合として報告されます。適用または復元後は対象プラグインを再読み込みしてください。パッチがノートを変更することはありません。

## よくある質問

**API Key は必要ですか？** 不要です。Trans-Hub アカウントを接続するだけで、モデルや API Key の設定は不要です。

**スマートフォンでも使えますか？** はい。実行時ローカライズはモバイルとデスクトップをサポートします。ファイル互換パッチはデスクトップでのみ利用できます。

**一部の文字が未翻訳なのはなぜですか？** 訳文待ち、ソースを検証できない、または UI を安全に識別できない可能性があります。プラグイン状態を確認してください。公開済み訳がまだないことは、その言語をサポートしないことを意味しません。

**プラグインにすでに中国語がある場合は？** 検出した内蔵訳を優先し、共有訳で不足を補います。レビュー済み修正は別の明示的な例外です。

**プラグイン更新後は？** 互換性を再確認します。再利用できる実行時項目は有効なまま、非互換項目は新しい版の訳を待ちます。ファイルパッチには依然として正確な一致が必要です。

**オフラインで使えますか？** 以前にキャッシュされ検証済みの訳は再利用できます。アカウント認可、不足内容の処理、新しい訳のダウンロードにはネットワークが必要です。

<!-- section: build -->
## ビルドとライセンス

Node.js 24 と pnpm 10.34.4 を使います。

```bash
pnpm install --frozen-lockfile
pnpm lint
pnpm type-check
pnpm test
pnpm verify:public-copy
pnpm build
```

Release タグは `manifest.json`、`package.json`、`versions.json` と一致する必要があります。`1.0.0` 未満は公開ベータ版です。[Apache-2.0](../LICENSE) ライセンスです。
