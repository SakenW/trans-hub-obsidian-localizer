Trans-Hub Localizer — это плагин, который обеспечивает перевод и локализацию интерфейса для плагинов сообщества Obsidian. Он в первую очередь сохраняет обнаруженные встроенные переводы плагинов, дополняет недостающий текст общими переводами и автоматически синхронизирует опубликованные обновления. По умолчанию переводы применяются во время работы, файлы плагинов не изменяются, а ваши заметки не переводятся и не загружаются.

## Начало работы

Требуются **Obsidian 1.11.4 или новее**, учётная запись Trans-Hub и подключение к сети для авторизации и синхронизации. Поддерживаются компьютеры и мобильные устройства; расширенные патчи совместимости файлов доступны только на компьютерах.

1. В разделе **Настройки → Сторонние плагины** установите и включите **Trans-Hub Localizer**.
2. Откройте настройки плагина и подключите учётную запись Trans-Hub. Настраивать модель ИИ, учётную запись поставщика модели или API Key не требуется.
3. Подтвердите язык перевода. Плагин автоматически обнаружит включённые плагины сообщества, и вы сможете исключить те, которые не нужно локализовать.

Уже опубликованные переводы используются напрямую; недостающий текст автоматически отправляется как запрос на локализацию, обрабатывается в фоне и синхронизируется после публикации. Текст, ожидающий обработки, публикации или проверки совместимости, может временно остаться на исходном языке.

При ручной установке скачайте `main.js`, `manifest.json` и `styles.css` из одного и того же [GitHub Release](https://github.com/SakenW/trans-hub-obsidian-localizer/releases) и поместите их в `<vault-config-dir>/plugins/trans-hub-plugin-localizer/`. Не смешивайте файлы разных версий.

## Основные возможности

| Возможность | Фактический эффект |
| --- | --- |
| Приоритет встроенных переводов | Сохраняет обнаруженные встроенные переводы текущего плагина и дополняет недостающий текст. Только явно проверенные исправленные переводы могут заменить соответствующий встроенный текст. |
| Общие переводы | Разные пользователи повторно используют опубликованные результаты, а недостающий текст поступает в общий процесс локализации. |
| Автоматическая синхронизация | При запуске сначала восстанавливает проверенные кэшированные переводы, а во время работы продолжает искать обновления. Для получения новых переводов требуется подключение к сети. |
| Повторное использование после обновления | Переводы времени выполнения, прошедшие проверку совместимости для каждого элемента, можно использовать между версиями плагина; неоднозначный или несовместимый текст пропускается. |
| Охват интерфейса | Поддерживаются безопасно распознаваемые названия, описания, настройки, кнопки, команды, уведомления, параметры, всплывающие подсказки, подсказки ввода, метки доступности и часть динамического текста. |
| Текст README плагинов | При наличии соответствующего опубликованного перевода README можно локализовать поддерживаемый текст на странице сведений о плагине сообщества; README и основной охват интерфейса учитываются отдельно. |

Во время работы в зависимости от условий применимости проверяются идентичность источника, область действия, семантическая роль, формат и динамические заполнители. Полный перевод всего интерфейса каждого плагина не гарантируется.

## Поддержка всех языков

Целевые языки не ограничены фиксированным списком. Можно выбрать распространённый язык или ввести языковой идентификатор через поле для другого языка, сохранив региональные и письменные варианты.

Быстрый выбор включает **китайский упрощённый, китайский традиционный, английский, японский, корейский, немецкий, французский, испанский, бразильский португальский и русский**. Доступны и другие языки, например итальянский (`it`), арабский (`ar`), украинский (`uk`) и сербский вариант на латинице (`sr-Latn`). Доступность и качество конкретных переводов зависят от опубликованных результатов и сервисов обработки, доступных для соответствующего языка.

Здесь имеются в виду **языки перевода других плагинов**. Интерфейс настроек самого Trans-Hub сейчас доступен на китайском упрощённом и английском языках; для других языков используется английский. Ссылки на языки вверху страницы переключают только язык чтения этого README.

## Качество перевода и область поддержки

Сейчас большинство переводов Trans-Hub сгенерировано машиной и не вычитано человеком. Плагин различает источник перевода и статус проверки. Успешная проверка источника и совместимости не означает, что точность перевода проверена человеком.

Этот процесс предназначен для плагинов сообщества, чью идентичность и версию можно подтвердить через официальный каталог сообщества Obsidian и надёжные исходные репозитории. Установка через BRAT, закрытые плагины или любые локальные изменения не получают гарантию совместимости автоматически. В текущем процессе исходным языком является английский.

Редактор Markdown заметок, режим чтения, код, скрипты и редактируемое содержимое исключены. Локализация README ограничена страницей сведений о плагине сообщества и не включает перевод заметок.

## Конфиденциальность и необязательные файловые патчи

- Локальное сканирование используется для определения версии плагина и поддерживаемого текста интерфейса; отсканированный текст интерфейса или заметки не загружаются.
- Запросы содержат идентичность плагина, версию, целевой язык, счётчики охвата и криптографический дайджест. Для авторизации учётной записи и загрузки переводов нужен доступ к сети.
- Учётные данные хранятся в защищённом хранилище Obsidian; об обработке на стороне сервера см. [политику конфиденциальности](https://trans-hub.net/zh-CN/legal/privacy).
- Локализация во время работы по умолчанию не перезаписывает файлы плагинов. При выключении она восстанавливает текст времени выполнения, в котором остаются значения переводов, и сохраняет последующие активные изменения, внесённые другими плагинами.

**Расширенный режим совместимости доступен только на компьютерах и по умолчанию выключен.** Для каждого подходящего плагина необходимо явно применить патч. Патч изменяет только проверенный статический текст интерфейса, привязанный к точной версии и артефакту, и сначала сохраняет резервную копию и запись о применении. Восстановление выполняется только если файл всё ещё соответствует дайджесту после патча; обновления плагина или внешние изменения сохраняются и сообщаются как конфликты. После применения или восстановления патча необходимо перезагрузить целевой плагин. Патч никогда не изменяет заметки.

## Частые вопросы

**Нужен ли API Key?** Нет. Достаточно подключить учётную запись Trans-Hub; настройка модели или API Key не требуется.

**Можно ли использовать на телефоне?** Да, локализация во время работы поддерживает мобильные устройства и компьютеры. Патчи совместимости файлов доступны только на компьютерах.

**Почему часть текста всё ещё не переведена?** Возможно, перевод ещё ожидается, источник нельзя подтвердить или интерфейс нельзя безопасно распознать. Проверьте состояние плагина; отсутствие опубликованного перевода ещё не означает, что язык не поддерживается.

**Что делать, если плагин уже содержит китайский язык?** Обнаруженные встроенные переводы сохраняются в приоритете, а общий перевод дополняет недостающие части; проверенные исправления являются отдельным, явным исключением.

**Что происходит после обновления плагина?** Совместимость проверяется повторно; пригодные для повторного использования элементы времени выполнения продолжают действовать, а несовместимые элементы ждут перевод новой версии. Файловые патчи по-прежнему требуют точного совпадения.

**Можно ли использовать офлайн?** Да, можно повторно использовать ранее кэшированные и проверенные переводы. Для авторизации учётной записи, обработки недостающего текста и загрузки новых переводов необходимо подключение к сети.

## Сборка и лицензия

Используйте Node.js 24 и pnpm 10.34.4:

```bash
pnpm install --frozen-lockfile
pnpm lint
pnpm type-check
pnpm test
pnpm verify:public-copy
pnpm build
```

Тег Release должен совпадать с `manifest.json`, `package.json` и `versions.json`. Версии ниже `1.0.0` являются публичной бета-версией. Лицензия — [Apache-2.0](../LICENSE).
